# 轻迹：趋势画布

先完成此方向说明和 `home-artboard.svg`，审视画布后再改产品代码。

## 设计任务

打开应用，第一眼看见体重如何变化。首页承担一个任务：读懂自己的体重轨迹，然后决定是否记录。其他信息通过真正的独立页面进入。

## 采用的技能与依据

- [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)：已安装并读取完整 `SKILL.md`，执行方案、审视、实现、截图批评四步。
- [Apple HIG Charts](https://developer.apple.com/design/human-interface-guidelines/charts)：数据本身最突出，坐标和解释退后；关键结论无需悬停才能看到，图表支持进一步探索。
- [Apple HIG Layout](https://developer.apple.com/design/human-interface-guidelines/layout)：聚焦主要内容、适应窗口变化、关键操作放在稳定且容易找到的位置。

技能以后也可在新回合自动识别；本回合已直接读取并应用。

## 方案比较

**选择：一笔曲线，一个读数。** 水平导航、无卡片的趋势画布，最近体重与曲线末端构成一个整体。视觉重心来自测量轨迹的形状。

```text
轻迹                     趋势  日历  记录  偏好            示例  + 记录

体重                                                7天  30天  90天  全部
近30天 -1.7 kg

   74.6 ─╲
          ╲_╱╲___
                 ╲___╱╲
                       ╲____╱╲__● 72.9 kg
                                  最近记录 10月25日
   9/27           10/7           10/16          10/26

实测体重   7日均值                       查看记录     调整目标
```

**舍弃：大数字加统计卡片。** 虽然容易扫描，但会继续把首页切碎，曲线仍只是其中一个模块，与本次要求冲突。

## 令牌

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 白瓷 | `#FBFBFC` | 页面基底 |
| 纯白 | `#FFFFFF` | 控件表面 |
| 石墨 | `#25282F` | 正文和读数 |
| 灰 | `#676E7A` | 日期与辅助文字，截图审视后提高对比度 |
| 雾线 | `#E7E9EE` | 坐标和必要分隔 |
| 鸢尾 | `#7774C7` | 唯一图表强调色 |

字体使用平台原生 UI 字体：macOS 为系统 San Francisco，Windows 为 Segoe UI，中文使用系统中文回退。大读数用细字重及紧字距，正文维持 13–15 px；不添加装饰性英文眉题。

页面边距随窗口在 21–80 px 间变化；首页主体外框最大宽度 1760 px，含边距。首页曲线占内容区的大部分高度。输入、按钮和导航按各自用途设置圆角，内容区域不套统一卡片。

## 页面与行为

- `/`：趋势画布；7 / 30 / 90 天及全部范围、当前体重、区间变化、实测和均值开关；日历和历史表不出现于首页。
- `/calendar`：按月看记录，选中日期在旁侧查看，窄屏详情移到下方。
- `/entries`：完整记录、查找、筛选、分页、编辑与删除。
- `/insights`：从首页选择进入，查看描述统计、近 13 周记录分布和个人目标。
- `/settings`：个人、外观、数据、接口四个设置分区，一次只显示选中分区。
- 顶部“记录”始终可见，保留 `N` 快捷键、深浅主题和独立示例空间。
- 导航拥有独立 URL，支持刷新和浏览器前进后退；兼容旧 hash 链接。

## 实现前自我审视

1. 初稿曾考虑暖白加陶土色；技能指出这种组合也已成为通用生成式模板，因此改为冷白与低饱和鸢尾色。
2. 移除情绪标语、假窗口按钮、头像、重复的本地隐私徽章、彩色统计卡和装饰小图标。
3. 大数字只保留真实体重，直接附着在轨迹末端；它是测量的读数，而不是营销标题。
4. 缺失日期仍保留断点，不为了曲线连续而补造记录。艺术感来自比例、排版、线条和留白。
5. 深色保持相同层级；手机上将读数移到图表上方，保留尽可能大的可触摸绘图区。

## 完成标准

首页无需滚动即可读到变化；非首页内容不混入首页；图表有可读尺度与交互；独立 URL 和快捷录入有效；浅色、深色及窄屏均经实际截图检查；已有数据与 API 契约保持兼容。

## 实现后的截图审视

- 1600 × 1000 桌面截图中，曲线是主体，最近体重贴近末端，读数与图表共同组成视觉重心。首页内容区无需滚动，没有历史表、日历和统计卡片。
- 深色沿用同一构图，只调整表面、文字和图线亮度；保留缺失日期的真实断点。
- 细小辅助文字从初稿的浅灰加深，保持图表层级的同时提高日期、标签和操作的可读性。
- 390 × 844 窄屏将最近体重移到曲线上方，绘图区保持全宽。记录页第一轮存在横向滚动，修订后保留日期、体重、变化及操作，随记通过编辑查看。
- 偏好一次只呈现一个分区，并支持方向键切换。所有图像来自内存示例数据。
