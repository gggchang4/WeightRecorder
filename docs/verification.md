# 验证记录

初次实现与浏览器验证：2026-10-23。趋势画布重设计与本轮验证：2026-10-26。

## 自动化

使用 Node.js 24、TypeScript 5.9、真实的 `node:sqlite` 和临时 HTTP 服务。测试覆盖：

- 闰年、无效日期、跨年与夏令时附近的自然日运算。
- 公斤与磅换算、空值处理、按自然日计算的 7 日均值。
- 连续记录遇缺失日中断，以及今天尚未记录时从昨天开始计数。
- 增重、减重、达到或跨过目标的进度边界。
- 图表缺失日不补测量值，7 日均值只取对应自然日窗口；全部范围不截断有效历史。
- CSV 的中文、逗号、引号、多行备注、UTF-8 BOM、公式保护与无效输入。
- 示例数据独立生成，默认截止昨天，不污染个人库。
- 真实 HTTP → 校验 → SQLite → 响应流程：创建、编辑、重复日期、未来日期、单位设置、筛选、导出、删除。
- 导入前全量校验、重复日期保留本地、失败后记录和偏好一起回滚。
- 数据库重新连接后读取持久化结果，以及 `PRAGMA integrity_check`。
- Host / Origin 边界、JSON 请求格式、未知路由与只读 Agent 上下文。

执行 `pnpm test` 与 `pnpm build` 可重复这些验证。测试数据库使用系统临时目录，与 `data/weight-recorder.sqlite` 隔离。

## 实际浏览器与启动器

原版在 Windows / Chrome 桌面视口和约 667 px 的 Codex 内置浏览器窄屏布局中验证了持久化流程。

- 示例空间录入后，体重、均值、连续记录和目标进度同步更新。
- 独立生产测试库的浏览器录入 → API → SQLite → 刷新后读回已验证。
- 同日期再次录入进入更新状态，编辑后不新增重复日期。
- 日历显示已保存的体重与随记，未来日期禁用。
- 设置页面从 kg 切换到 lb 后，数据库仍为 `70.2 kg`，目标仍精确保留 `65 kg`，界面按 lb 换算。
- 实际执行 Windows `启动轻迹.cmd -NoBrowser -Port 3211`，正确识别并复用已运行的轻迹服务。
- 生产启动器可完成构建、启动回环服务和报告本地地址。
- 已读取浏览器错误 / 警告日志，验证期间没有应用错误。

- 先完成方向文档和 SVG / PNG 设计稿，经查看后实现；依据 Anthropic frontend-design 与 Apple HIG Charts / Layout。
- Windows / Chrome 实际检查 1600 × 1000、2560 px 宽桌面，以及 390 × 844 手机视口。浅色、深色首页、日历、记录、偏好和独立概况均已查看。
- 1600 × 1000 首页内容区的 `scrollHeight` 与 `clientHeight` 均为 892 px，无需滚动；DOM 中没有记录表或日历。

- 浏览器错误 / 警告日志为空。已有 11 项自动化测试和生产构建通过。
